# Trae Platform 部署与分享指南

如何让你的 Trae 平台环境给其他人使用。

---

## 一、局域网内使用（最简单）

你的应用已绑定 `0.0.0.0`，同一局域网内的设备可以访问。

### 1. 启动服务

```bash
cd d:\trae-code\trae_platform
python app.py
```

### 2. 获取本机 IP

**Windows：**
```cmd
ipconfig
```
找到「IPv4 地址」，例如 `192.168.1.100`

**Mac/Linux：**
```bash
ifconfig
# 或
ip addr
```

### 3. 其他人访问

在同一 WiFi/局域网内的同事，在浏览器打开：

```
http://你的IP:5000
```

例如：`http://192.168.1.100:5000`

---

## 二、Docker 部署（适合服务器）

### 1. 构建并启动

```bash
cd d:\trae-code\trae_platform
docker-compose up -d
```

### 2. 访问

- 本机：`http://localhost:5000`
- 局域网：`http://服务器IP:5000`

### 3. 注意事项

- **ADB 设备**：若需连接 Android 设备，需在宿主机安装 ADB，或使用 `network_mode: host` 共享宿主机网络
- **数据持久化**：`data/`、`reports/`、`logs/` 已挂载到宿主机

---

## 三、公网访问（需谨慎）

若要让外网访问，需要：

### 方案 A：内网穿透（ngrok / frp 等）

1. 安装 ngrok：https://ngrok.com/
2. 启动 Trae 后执行：
   ```bash
   ngrok http 5000
   ```
3. 会得到一个公网 URL，例如 `https://xxx.ngrok.io`

### 方案 B：部署到云服务器

1. 将代码部署到云服务器（阿里云、腾讯云等）
2. 开放 5000 端口
3. 通过公网 IP 或域名访问

### 安全建议（公网必须做）

1. **启用 API 认证**：
   ```bash
   set ENABLE_API_AUTH=1
   set API_KEY=你的强密码
   ```
   启用后，API 请求需在 Header 中携带 `X-API-Key: 你的强密码`

2. **使用 Nginx 反向代理**：隐藏端口、配置 HTTPS
3. **防火墙**：只开放必要端口

## 四、分享代码给同事

### 1. 通过 Git

```bash
# 在项目目录
git init
git add .
git commit -m "Trae Platform"
# 推送到 GitLab/GitHub/内网 Git
git remote add origin <你的仓库地址>
git push -u origin main
```

同事克隆后：

```bash
git clone <仓库地址>
cd trae_platform
pip install -r requirements.txt
python app.py
```

### 2. 打包分享

```bash
# 排除不必要的文件
# 建议排除：logs/、data/、__pycache__/、.git/
# 保留：代码、requirements.txt、config/
```

## 五、环境变量速查

| 变量 | 说明 | 何时需要 |
|------|------|----------|
| `ENABLE_API_AUTH=1` | 启用 API 认证 | 公网/多人环境 |
| `API_KEY=xxx` | API 密钥 | 启用认证时 |
| `SONG_ORDER_HOST` | 点歌服务主机 | 使用点歌模块 |
| `LOG_DIR` | 日志目录 | 自定义日志路径 |
| `RUNTIME_DATA_DIR` | Runtime 数据目录 | 自定义数据路径 |

## 六、快速检查清单

- [ ] 服务已启动：`python app.py`
- [ ] 本机可访问：`http://localhost:5000`
- [ ] 防火墙已放行 5000 端口（若局域网访问失败）
- [ ] 同事与你在同一局域网
- [ ] 公网部署时已启用 `ENABLE_API_AUTH` 和 `API_KEY`

## 七、常见问题

**Q：同事访问提示「无法访问此网站」？**
- 检查防火墙是否放行 5000 端口
- 确认同事与你在同一网络
- 确认服务已启动且绑定 `0.0.0.0`

**Q：ADB 设备连接不上？**
- 设备需与运行 Trae 的机器在同一网络
- 或通过 USB 连接运行 Trae 的机器

**Q：如何修改端口？**
- 修改 `app.py` 最后一行的 `port=5000` 为其他端口
- Docker 部署时修改 `docker-compose.yml` 的 `ports: - "5000:5000"`
