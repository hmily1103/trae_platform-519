# PRD 智能审计系统 - 语音输入功能使用说明

为提升需求录入和测试用例补充的效率，我们在 PRD 审计模块中引入了**实时语音识别**功能。产品经理或测试工程师可以通过直接口述，快速将想法、一句话需求或会议中的讨论直接转化为文字，追加到 PRD 内容框中。

## 🎯 核心优势
- **即用即转**：无需打字，想到什么说什么，实时上屏。
- **零成本接入**：基于浏览器原生能力（Web Speech API），完全免费，不消耗第三方大模型或语音 API 额度。
- **保护隐私**：语音数据由浏览器底层引擎直接处理（如 Chrome 的 Google 引擎、Edge 的 Microsoft 引擎），不在平台服务器留存音频文件。

## ⚙️ 环境要求
- **推荐浏览器**：Microsoft Edge（国内网络最稳定、识别率最高）或 Google Chrome（需确保网络能访问 Google 服务）。
- **硬件要求**：电脑需配备并开启麦克风设备。
- **网络环境**：必须在**联网**状态下使用（浏览器需要将语音流送往云端识别引擎）。

## 📝 操作步骤

### 第一步：定位语音输入按钮
打开 [PRD 审计平台](/prd_audit/) 页面，在左侧**「输入 PRD」**面板的右上角区域，找到天蓝色的 **`<i class="fas fa-microphone"></i> 语音输入`** 按钮。

### 第二步：授权麦克风
首次点击该按钮时，浏览器顶部（地址栏附近）会弹出一个权限请求提示：“网页想要使用您的麦克风”。
- 请务必点击 **“允许”**。
- 如果不小心点了拒绝，可以在浏览器地址栏左侧的“锁形”图标中重新开启麦克风权限。

### 第三步：开始说话
授权成功后，按钮会变成红色的 **`<i class="fas fa-stop-circle"></i> 停止录音`**。
- 此时页面会弹出提示：“开始语音输入，请对着麦克风说话...”。
- 尽情对着麦克风描述需求即可。
- **实时效果**：你说话的过程中，识别出的文字会**实时、自动**追加到下方的文本框中。

### 第四步：结束输入
说完之后，再次点击红色的 **“停止录音”** 按钮。
- 按钮恢复为天蓝色。
- 页面提示：“语音输入已结束”。
- 你可以对文本框中识别出的文字进行手动润色或修改，然后点击 **“一键体检 / 深度审计”** 进行常规的 PRD 分析流程。

## ⚠️ 常见问题排查 (FAQ)

**Q1：点击“语音输入”后，提示“您的浏览器不支持语音识别功能”怎么办？**
**A**：说明你当前使用的浏览器内核不支持 Web Speech API。请更换为最新版的 Microsoft Edge 或 Google Chrome 浏览器。

**Q2：按钮变成了红色，但我说话屏幕上没有出现文字？**
**A**：
1. **网络问题**：如果你用的是 Chrome 浏览器，由于国内网络原因，可能无法连接到 Google 的语音服务器。**强烈建议切换到 Edge 浏览器使用此功能。**
2. **麦克风故障**：请检查电脑系统的声音设置，确保默认麦克风正在工作且音量正常。

**Q3：可以说方言或英文吗？**
**A**：系统目前默认设置为 `zh-CN`（简体中文）。普通的普通话识别率极高，部分口音较轻的方言也能识别，但不建议中英文重度夹杂。

**Q4：我可以上传会议录音（MP3/WAV）进行识别吗？**
**A**：目前该功能仅支持**实时口述**。如果您有离线长录音文件的转写需求，请联系管理员评估是否接入第三方收费的语音转写 API（如火山引擎、讯飞等）。
