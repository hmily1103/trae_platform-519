# 代码级精准回归测试工具 (独立体验版)

这是一个轻量级的「精准测试/变更影响分析」工具，完全脱离了主平台，可单独运行。你可以将此包发给你的同事直接进行演示。

## 核心能力
1. **无需配置重量级的静态代码分析工具** (如 JavaParser, Babel 等)。
2. 直接粘贴 `Git Diff` 片段或修改前后的代码。
3. 利用大模型(LLM)的语义理解能力，自动推导该代码变更的 **爆炸半径** (受影响的上下游接口、前端组件) 并生成 **精准回归测试策略**。

## 运行环境要求
- Python 3.8+
- 安装依赖包:
  ```bash
  pip install flask requests
  ```

## 如何运行
1. 进入本文件夹目录。
2. **配置大模型（重要）**：打开 `config.json`，把里面的 `api_key` 换成你自己的大模型 Key（默认支持 DeepSeek 和 豆包）。
3. 运行启动脚本：
   ```bash
   python app.py
   ```
4. 在浏览器中打开：[http://127.0.0.1:5001](http://127.0.0.1:5001)

## 使用方法
在页面的左侧输入框中粘贴代码的 `Git Diff` 内容（如终端执行 `git diff` 或 Gitlab MR 上的 diff 片段），点击“一键推导回归策略”，即可在右侧查看自动生成的 Markdown 分析报告。

## 目录结构
- `app.py`: Flask 主启动入口
- `views.py`: 核心路由与大模型 Prompt 控制逻辑
- `templates/`: 前端 HTML 页面 (纯前端实现，引入了 Bootstrap 和 marked.js)
- `utils/llm_client.py`: 大模型调用客户端 (复用了原平台的对接逻辑)
