# Streamlit Web界面使用指南

## 🚀 快速启动

### Windows 用户

```batch
# 双击运行
启动Web界面.bat
```

### Linux/Mac 用户

```bash
# 添加执行权限
chmod +x 启动Web界面.sh

# 运行
./启动Web界面.sh
```

### 手动启动

```bash
# 安装依赖（首次运行）
pip install streamlit pandas

# 启动界面
cd trae_platform/modules/player_stress
streamlit run streamlit_app.py
```

启动后，浏览器会自动打开 `http://localhost:8501`

## 📋 界面功能说明

### 左侧边栏 - 配置参数

#### 1. 设备与应用
- **选择设备**: 下拉选择已连接的设备（自动检测）
- **播放器包名**: 输入要监控的应用包名

#### 2. KTV专项策略
- **监控目标屏**: 多选 Display 0（点歌屏）/ Display 1（电视屏）
  - 建议：只选择 Display 1（电视屏），避免点歌屏干扰
- **监控强度**: 三种模式
  - **极低功耗**: 仅监控RK硬件节点，零性能影响
  - **标准模式**: 增加FPS采集和30s间隔截图（推荐）
  - **深度压测**: 高频截图+模拟点歌

#### 3. 测试模式
- **纯监控（不干扰播放）**: 只监控，不主动操作（推荐）
- **固定间隔切歌**: 按固定时间间隔自动切歌
- **循环播放**: 循环播放指定歌曲列表

#### 4. 测试时长
- 滑动条设置监控时长（10-1440分钟）
- 建议至少60分钟以获得足够的统计数据

#### 5. HTTP点歌配置（可选）
- 如果使用HTTP点歌功能，可以配置服务器IP、机顶盒IP和歌曲列表

#### 6. 环境检查
- 自动显示Root权限状态
- 自动显示检测到的电视端Display ID

---

### 主界面

#### 1. 测试控制
- **▶️ 开始监控**: 启动测试（配置完成后点击）
- **⏹️ 停止测试**: 停止正在运行的测试
- **状态指示**: 显示当前测试状态（运行中/未运行）

#### 2. 实时状态看板
显示关键指标：
- **视频FPS**: 电视端视频帧率
- **解码器工作计数**: RK硬件解码器工作计数及增量
- **解码器状态**: 是否卡死
- **电视端卡顿**: 是否检测到卡顿

**趋势图**:
- 视频FPS趋势（折线图）
- 解码器工作计数趋势（折线图）

#### 3. 实时日志
- 显示最近20条日志
- 实时更新测试进度和状态

#### 4. 报告查看
- 列出最近5个测试报告
- 点击报告名称可查看详细内容

## 💡 使用建议

### 推荐配置（标准监控）

```
设备: 自动选择第一个
包名: com.thunder.ktv:media
监控目标屏: Display 1 (电视屏)
监控强度: 标准模式
测试模式: 纯监控（不干扰播放）
测试时长: 60-120分钟
```

### 极低功耗配置（零干扰）

```
监控强度: 极低功耗
- 仅监控RK硬件节点
- 不进行截图和FPS采集
- 完全不影响播放性能
```

### 深度压测配置（全面检测）

```
监控强度: 深度压测
测试模式: 循环播放
- 高频截图对比
- 自动切歌测试
- 全面检测卡顿
```

## 🔍 关键指标说明

### 电视端卡顿判定（优先级从高到低）

1. **解码器卡死** 🚨
   - `work_count` 停止增长
   - 最可靠的指标，直接反映硬件层状态

2. **画面冻结** 🚨
   - 连续3秒画面完全静止
   - 最直观的指标，直接看到画面是否静止

3. **视频FPS过低** ⚠️
   - FPS < 15 表示严重卡顿
   - FPS < 20 表示可能存在卡顿

4. **日志卡顿** ⚠️
   - 播放器内部报告的卡顿
   - 非常准确，但可能不会上报到logcat

### 点歌屏UI丢帧（仅供参考）

- **UI Jank**: 仅反映点歌屏UI线程负载
- **不影响电视端视频质量**
- 可以忽略此指标

## 🐛 故障排查

### 问题1: 无法启动Web界面

**解决方案**:
```bash
# 检查Streamlit是否安装
pip install streamlit pandas

# 检查Python版本（需要3.7+）
python --version
```

### 问题2: 无法检测到设备

**解决方案**:
1. 确保设备已通过USB或网络ADB连接
2. 运行 `adb devices` 确认设备列表
3. 刷新页面重新检测

### 问题3: Root权限不可用

**影响**: 硬件解码监控（work_count增量检测）将无法使用

**解决方案**:
1. 开启设备Root权限
2. 测试Root权限：`adb shell "su -c 'id'"`
3. 应该返回 `uid=0`

### 问题4: 无法获取视频FPS

**调试步骤**:
1. 在播放视频时运行：
```bash
adb shell dumpsys SurfaceFlinger --display-id 1 --list
```

2. 将输出内容保存，可能需要调整Surface过滤关键字

## 📊 报告查看

测试结束后，报告保存在 `reports/` 目录：

- `summary_YYYYMMDD_HHMMSS.txt` - 文本报告（推荐查看）
- `summary_YYYYMMDD_HHMMSS.json` - JSON数据
- `report_YYYYMMDD_HHMMSS.csv` - CSV数据

在Web界面右侧可以：
- 查看最近5个报告列表
- 点击报告名称查看详细内容

---

## 🔄 自动刷新

Web界面会自动刷新（每2秒），显示：
- 实时状态指标
- 最新日志
- 趋势图更新

如果测试正在运行，页面会自动刷新，无需手动刷新浏览器。

---

## 📱 移动端访问

Streamlit支持移动端访问，可以在手机或平板上：
1. 确保手机和电脑在同一网络
2. 在电脑上查看Streamlit启动时显示的IP地址
3. 在手机浏览器访问：`http://<电脑IP>:8501`

## ⚙️ 高级配置

### 修改刷新间隔

编辑 `streamlit_app.py`，找到：
```python
# 自动刷新（如果测试正在运行）
if st.session_state.test_running:
    pass
```

可以添加 `time.sleep()` 控制刷新频率。

### 自定义报告目录

在配置中修改：
```python
"report": {
    "output_dir": "自定义目录"
}
```
