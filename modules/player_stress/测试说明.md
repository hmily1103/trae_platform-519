访问：`http://localhost:5000/player_stress/`

#### 配置参数：
- **设备ID**: `192.168.16.105:8787`
- **包名**: `com.thunder.ktv:media`
- **测试模式**: `monitor_only`（纯监控）
- **测试时长**: `10` 分钟

#### 操作步骤：
1. 打开配置标签页
2. 选择设备（如果未自动连接，需要先连接设备）

- 实时监控标签页应显示：
  - 视频FPS（可能为0或N/A，因为极低功耗模式）
  - 解码器工作计数（应该有数值）
  - 解码器状态（正常/卡死）
  - CPU使用率
  - 内存占用
  - FPS趋势图
  - 工作计数趋势图

- 实时日志标签页应显示：
  - 启动日志
  - 监控循环日志（每5秒一次）
  - 快照采集日志

- 测试结束后：
  - 自动生成报告

## 可能的问题排查

### 问题1：设备连接失败
- 检查 `adb devices` 是否能看到设备
- 如果是网络设备（IP:端口），需要先连接：`adb connect 192.168.16.105:8787`

### 问题2：实时监控没有数据
- 检查监控循环是否在运行（查看日志）
- 等待几秒钟，数据需要时间采集
- 如果启用"极低功耗"模式，FPS可能为0（这是正常的）

### 问题3：性能指标一直显示"等待数据..."
- 检查 `TestRunner.monitor.history` 是否有数据
- 检查日志中是否有错误信息
- 确保监控循环正在运行

### 问题4：报告没有生成
- 检查测试是否正常结束（不要强制关闭）
- 检查 `reports` 目录是否存在
- 查看日志中是否有报告生成相关的错误

## 当前代码已知问题

### 1. Flask views.py 配置不完整
当前 `api_start_test` 函数中，配置构建时**没有包含** `enable_screenshot` 和 `enable_fps` 参数。

**问题位置**：`views.py` 第118-120行
```python
'monitor': {
    'interval_seconds': 2  # 缺少 enable_screenshot 和 enable_fps
}
```

**影响**：无法使用"极低功耗"模式，始终使用默认配置（启用截图和FPS）

### 2. 前端没有监控模式选择
前端HTML中没有提供"监控模式"选择（极低功耗/标准模式/深度压测）

**问题位置**：`stress_index.html` 缺少监控模式选择控件

**影响**：无法选择不同的监控强度

## 建议的修复方案

需要在Flask界面中添加：
1. 监控模式选择（极低功耗/标准模式/深度压测）
2. 根据模式自动设置 `enable_screenshot` 和 `enable_fps`
3. 更新后端API接收这些参数
