# PRD 审计平台 - 功能说明书

## 一、产品定位

**PRD 审计平台** 是一款面向 KTV 行业的智能需求评审工具，基于"测试左移"理念，在产品需求文档（PRD）阶段自动识别逻辑漏洞、缺失项和冲突问题，帮助开发团队提前发现问题，减少后期返工。

---

## 二、解决什么问题

### 传统 PRD 评审的痛点

| 传统方式 | 我们解决的问题 |
|----------|--------------|
| 人工评审耗时 4-8 小时 | **AI 自动分析，2-5 分钟完成** |
| 依赖个人经验，容易遗漏 | **规则引擎系统，8 个固定维度** |
| 问题描述不清晰，沟通成本高 | **自动生成缺陷报告，对应具体章节** |
| 难发现隐藏的业务冲突 | **知识图谱推理，提前预警** |
| 测试要点靠人工梳理 | **自动生成测试矩阵，覆盖 5 大场景** |

---

## 三、核心功能

### 1. 智能PRD分析

**输入方式**（任选其一）：
- 🔗 飞书文档链接
- 📝 粘贴 PRD 文本
- 📄 上传 PDF 文件
- 📃 上传 Word 文档

**输出内容**：
- 📋 结构解析（模块、业务流程、接口列表）
- 🚨 漏洞清单（8 类问题分类）
- 📊 质量评分（0-10 分）
- 💡 修复建议

### 2. 漏洞扫描（8 维度）

系统自动检测以下 8 类问题：

| 类别 | 问题示例 |
|------|----------|
| D1 业务规则 | 规则冲突、口径不一致 |
| D2 状态机 | 状态跳转缺失、回滚未考虑 |
| D3 接口 | 返回字段不完整、协议模糊 |
| D4 权限 | 越权隐患、角色定义不清 |
| D5 校验 | 参数校验缺失、边界未定义 |
| D6 异常 | 失败重试、超时处理、弱网适配 |
| D7 歧义 | 描述模糊、可理解性差 |
| D8 其他 | 依赖缺失、遗漏项 |

### 3. 测试矩阵生成

根据 PRD 自动生成测试点矩阵，包括：

| 维度 | 说明 |
|------|------|
| 正常场景 | 核心功能正向验证 |
| 异常场景 | 错误输入、超限处理 |
| 边界条件 | 临界值、空值、极值 |
| 并发场景 | 多用户同时操作 |
| 中断恢复 | 断网/断电后恢复 |

### 4. 系统图生成

自动生成 Mermaid 格式的系统架构图：
- 状态机图
- 权限矩阵说明
- 并发冲突说明

### 5. 知识图谱推理

基于历史缺陷模式，推理潜在的隐藏风险，提前预警。

### 6. 学习进化

- 📦 每次审计自动保存快照
- 🧠 从历史样本学习，自动生成新规则
- 📈 质量看板（采纳率/发布率统计）

## 四、技术特色

### 六段式流水线

```
Stage1: 结构解析 → Stage2: 漏洞扫描 → Stage3: 大纲生成
    → Stage4: 测试矩阵 → Stage5: 系统图 → Stage6: 报告输出
```

各阶段**并行执行**，大幅提升分析效率。

### 多引擎协同

- 规则引擎：可扩展的漏洞检测规则库
- LLM 引擎：大模型辅助理解与报告生成
- 图谱引擎：知识推理与风险预测
- 向量引擎：语义搜索与知识检索

### 配置灵活

- 支持 OpenAI API
- 支持本地模型（Ollama、LM Studio）
- 可配置 Prompt 模板
- 规则库版本管理
