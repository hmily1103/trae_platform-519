指标说明
QPS（Queries Per Second）
每秒成功处理的请求数。数值越高表示接口吞吐能力越强。
平均延迟（Avg Latency）
所有成功请求响应时间的算术平均值，单位毫秒（ms）。反映接口整体响应速度。
P95 延迟（95th Percentile）
将全体成功请求的响应时间从小到大排序，取第 95% 位置的值。表示 95% 的请求在此时间内完成，用于评估「大多数用户」的体验。例如 P95=200ms 表示 95% 的请求在 200ms 内返回。
P99 延迟（99th Percentile）
取第 99% 位置的值。表示最慢的 1% 请求的耗时，用于发现长尾延迟问题。P99 过高说明有少量请求异常慢，需排查。
错误率
失败请求数 / 总请求数 × 100%。包含 HTTP 非 2xx 状态码、超时、连接异常等。
超时数
超过「单次超时」设定时间未返回的请求数量，计入失败。
