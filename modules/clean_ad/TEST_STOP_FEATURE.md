# 广告清理停止功能测试指南

## 功能说明

广告清理功能已添加停止按钮，支持在清理过程中优雅停止任务。

## 测试步骤

### 1. 基本功能测试

1. **启动服务器**
   ```bash
   cd D:\trae-code\trae_platform
   python app.py
   ```

2. **访问页面**
   - 打开浏览器访问：http://127.0.0.1:5000/clean_ad/

3. **开始清理任务**
   - 输入服务器IP（例如：192.168.1.100）
   - 点击"一键开始清理"
   - 确认对话框，点击"确定"
   - 观察：
     - "开始清理"按钮应该隐藏
     - "停止清理"按钮应该显示并可用
     - 日志区域开始显示清理进度

### 2. 停止功能测试

#### 测试场景 1：在清理过程中停止

1. **开始清理任务**
   - 输入服务器IP并开始清理
   - 等待看到至少1-2个盒子正在处理

2. **点击停止按钮**
   - 点击"停止清理"按钮
   - 确认对话框，点击"确定"
   - 观察：
     - 按钮应该变为"正在停止..."（禁用状态）
     - 应该显示Toast提示："停止信号已发送，等待当前盒子清理完成..."
     - 日志中应该显示："停止信号已接收，当前盒子清理完成后将停止"

3. **等待当前盒子完成**
   - 观察日志，当前盒子应该继续清理完成
   - 完成后应该显示："当前盒子清理完成，任务已停止"

4. **查看统计信息**
   - 应该显示完整的统计信息：
     - 总计：X
     - 已处理：Y
     - 成功：Z
     - 失败：W
     - 剩余：N（如果停止）
   - Toast应该显示："清理任务已停止"

5. **UI状态恢复**
   - "开始清理"按钮应该重新显示并可用
   - "停止清理"按钮应该隐藏

#### 测试场景 2：快速停止（在开始处理前）

1. **开始清理任务**
   - 输入服务器IP并开始清理
   - 立即点击"停止清理"（在获取到设备列表后，但在开始处理前）

2. **观察结果**
   - 应该显示："任务已停止（在开始处理前）"
   - 统计信息应该显示：已处理 0，剩余为总数

#### 测试场景 3：正常完成（不停止）

1. **开始清理任务**
   - 输入服务器IP并开始清理
   - 不点击停止，等待所有盒子处理完成

2. **观察结果**
   - 应该显示完整的统计信息
   - Toast应该显示："清理任务完成！"
   - 统计信息中不应该有"剩余"字段

### 3. 错误处理测试

#### 测试场景 4：重复停止

1. **开始清理任务**
2. **点击停止按钮**
3. **再次点击停止按钮**
   - 应该显示Toast："没有运行中的清理任务"或API返回错误

#### 测试场景 5：连接中断

1. **开始清理任务**
2. **在清理过程中关闭浏览器标签页或刷新页面**
   - 后端任务应该继续运行（这是正常的）
   - 刷新后可以重新开始新任务

### 4. 边界情况测试

#### 测试场景 6：单个盒子清理

1. **使用只有1个设备的服务器IP**
2. **开始清理**
3. **在清理过程中点击停止**
   - 应该等待当前盒子完成后再停止

#### 测试场景 7：空设备列表

1. **使用没有设备的服务器IP**
2. **开始清理**
   - 应该显示："成功获取到 0 个唯一的机顶盒IP"
   - 应该正常完成，不报错

## 预期行为总结

### ✅ 正常行为

- 停止按钮只在清理过程中显示
- 点击停止后，当前盒子会完成清理
- 停止后会显示完整的统计信息
- UI状态正确恢复
- 日志保留所有信息

### ❌ 不应该出现的情况

- 停止后不应该继续处理新的盒子
- 不应该中断正在执行的ADB操作
- 不应该出现JavaScript错误
- 不应该出现后端错误（除非是预期的，如任务不存在）

## 调试技巧

### 查看后端日志

```bash
# 查看平台日志
cat logs/platform.log

# 查看清理模块日志
grep "clean_ad" logs/platform.log
```

### 浏览器控制台

- 打开浏览器开发者工具（F12）
- 查看Console标签页，检查是否有JavaScript错误
- 查看Network标签页，检查API请求是否正常

### 常见问题

1. **停止按钮不显示**
   - 检查JavaScript控制台是否有错误
   - 确认 `currentTaskId` 是否正确设置

2. **停止后继续处理**
   - 检查后端日志，确认停止信号是否正确发送
   - 检查 `stop_event.is_set()` 是否正确检查

3. **统计信息不正确**
   - 检查 `processed_count` 是否正确递增
   - 检查 `remaining_count` 计算是否正确
